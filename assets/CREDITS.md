# Visual assets

The profile's vector graphics use a shared neutral palette with one blue accent. The geometry is decorative and does not represent measured project data.

- Thales mark: sourced from the [official Thales website asset](https://cpl.thalesgroup.com/sites/default/files/content/thales-logo-building-a-future-we-can-all-trust.svg), used to identify employment affiliation.
- 42 mark: sourced from [Simple Icons](https://github.com/simple-icons/simple-icons/blob/develop/icons/42.svg), whose icon collection is distributed under CC0; used to identify study at 42 Beirut.

Institution marks belong to their respective owners. This repository is Mahdi Hajj Hassan's personal portfolio.
